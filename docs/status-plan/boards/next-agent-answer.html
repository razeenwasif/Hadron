3.5 Positional Encoding

1With no recurrence and no convolution, the model has to be told where each token sits if it is to use the order of the sequence. Positional encodings are added to the input embeddings at the bottom of the encoder and decoder stacks. They share the embeddings’ dimension, so the two can be summed.

PE(pos, 2i)   = sin(pos / 10000^(2i / d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i / d_model))

Each dimension is a sinusoid, with wavelengths in a geometric progression from 2π to 10000 · 2π, so a fixed offset becomes a linear function of the encoding.

2Learned positional embeddings gave nearly identical results. The sinusoidal version was kept because it may let the model extrapolate to longer sequences than it saw in training.

4 Why Self-Attention

Self-attention layers are compared with recurrent and convolutional ones on three counts: computation per layer, how much can run in parallel, and the path length between distant positions.

What do positional encodings add?

Word order. Attention on its own reads the input as a set, so it can’t tell which token came first. Positional encodings add a position signal to each token’s embedding1. The paper uses fixed sine and cosine waves; learned embeddings scored about the same, and the waves may stretch to inputs longer than any in training2.
