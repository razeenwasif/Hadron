Hadron Core

FREE · MPL-2.0

The complete native Rust browser and local research stack — no telemetry, no accounts required, and no locked privacy toggles.

  • Native WKWebView / WebView2 multi-webview engine
  • Shields tracking defense, Tor & Private containers
  • Tachyon GPU terminal & Neutron file browser
  • Local Notebook RAG, Trail graph, & encrypted Vault
  • Bring-Your-Own-Key AI (Ollama / Claude / OpenAI / Fairy)
  • Encrypted folder sync via iCloud Drive, Syncthing, or NAS

Hadron+

OPTIONAL CLOUD

Optional server-backed infrastructure for people who want hosted convenience across macOS, iOS, and Android.

  • Zero-knowledge multi-device Cloud Sync (Desktop + iOS)
  • Per-workspace Privacy Relay & continuity handoff
  • One-click @hadron.id masked email aliases
  • Background cloud page-watchers while devices sleep
